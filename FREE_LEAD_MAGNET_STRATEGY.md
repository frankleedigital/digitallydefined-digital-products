# Free Lead Magnet Strategy

Every paid product must have a lead-generating asset attached to it. This document
defines the free lead magnet, its format, target audience, pain point, and desired
transformation for every product.

## Lead Magnet Type Key

| Type | Description |
|---|---|
| Quiz | Diagnostic/scoring assessment |
| Checklist | Quick-reference action list |
| Scorecard | Validation/ranking framework |
| Blueprint | Ready-to-execute plan template |
| Mini Guide | Short PDF (5-15 pages) |
| Workbook | Guided fillable document |
| Calculator | Interactive tool with output |
| PDF | Static guide |
| Prompt Pack | Prompt templates |
| Assessment | Scored profile breakdown |
| Cheat Sheet | Quick-reference command sheet |
| Template | Reusable Notion/structure template |
| Challenge | 7-day email/nurture journey |
| Training Video | Screen-share tutorial |
